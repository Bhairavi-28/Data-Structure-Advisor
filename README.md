# Data-Structure-Advisor



Data Structure Advisor

A CLI-based tool that helps users choose the optimal data structure based on a series of yes/no questions. The project evolves through multiple prototypes, integrating different approaches like DFS, Decision Trees, and Hashing to optimize performance and user experience.


---

Features

Prototype 1

Modules: Input Module, Output Module, Full Engine Module, Main Module

Functionality:

Modular design for easy scalability.

Basic yes/no decision-making logic.

Introduced the first full engine logic (FL) for prototype operations.



Prototype 2

Experimentation:

Incorporated Decision Tree and DFS to handle yes/no question sequences.

Introduced DFS-based data structure traversal for improved logic flow.

Better modularity and structured decision-making.



Prototype 3

Experimentation:

Added Hashing alongside Decision Tree and DFS.

Enabled faster lookups and improved handling of repeated questions.

Hybrid approach: Decision Tree + Hashing + DFS for smarter recommendation engine.



Prototype 4 (Final Integration)

Integration:

Combines the best of all prototypes.

Full Input and Output modules for user interaction.

Core engine integrates Hashing, Decision Tree, and DFS for maximum efficiency.

Provides an optimized and user-friendly data structure advisor.




---

Technologies Used

C (for core data structure algorithms)

CLI-based interface for simplicity and ease of use

---

How to Use

1. Clone the repository.
2. Navigate to the main directory.
3. Run the main engine file:
Main_mod.c (Prototype 4)
or main.c (Prototype 1)
5. Follow the yes/no prompts to get data structure recommendations.
